# MALHEM

Настольная игра в браузере: гексагональное поле, контроль узлов, рынок способностей,
синхронные партии на 2–4 игрока с приглашением по коду.

---

## Быстрый старт

```bash
cd malhem
chmod +x start.sh
./start.sh
```

Открой **http://localhost:5173** — сервер и клиент поднимутся сами.
Остановить: `Ctrl+C`.

### Запуск вручную (два терминала)

```bash
# терминал 1 — сервер (порт 8080)
cd malhem/server
npm install
npm start

# терминал 2 — клиент (порт 5173)
cd malhem/client
npm install
npm run dev
```

Требуется **Node.js 18+**.

### Чтобы поиграть с друзьями

1. Открой http://localhost:5173, введи ник, нажми **Создать партию**
2. Скопируй 6-значный код или ссылку и отправь друзьям
3. Друзья открывают ту же ссылку, вводят ник и код комнаты
4. Хост жмёт **Начать игру** (нужно минимум 2 игрока)

Играть по локальной сети: в `client/vite.config.js` уже стоит `host: true`,
так что друзья в той же сети заходят по `http://ТВОЙ_LAN_IP:5173`.

## Как устроена игра

### Два счётчика — и почему их два

| | **Очки** | **Ко́ины** |
|---|---|---|
| Что это | сумма всех захватов за партию | валюта |
| Когда растут | при захвате узла | доход в конце цикла + разовый куш за захват |
| Тратятся? | **нет, никогда** | да, на рынке |
| Роль в финале | **итог партии** | только тай-брейк при ничьей |

Узел даёт очки один раз при захвате — и они остаются навсегда, даже если узел отберут.
Параллельно каждый удерживаемый узел приносит Ко́ины в конце цикла (каждые 5 кругов).

Итого узел — это **две награды**: очки сразу и доход потом, пока держишь.

### Поле

Стартовое поле — 12 тайлов рубашкой вверх вокруг **Точки заражения**.
Каждый ход игрок вскрывает новые гексы и достраивает сеть, поэтому карта растёт органично.
Состав колоды — 53 тайла, ровно по таблице компонентов.

| Тайл | Сложность | Очки | Доход/цикл | Особенность |
|---|---|---|---|---|
| Базовый узел | авто | 1 | 1 C | |
| Средний узел | 4+ | 2 | 2 C | со «Скрипт-кидди» — 3+ |
| Сложный узел | 5+ | 4 | 3 C | только Продвинутый Прокси наскоком |
| Центральный Маршрутизатор | **только 6** | 6 | — | модификаторы не работают |
| Пустой гекс | — | — | — | связующее пространство |
| Антивирус | — | — | — | −2 C или потеря действия |
| Карантин-зона | — | — | — | ход окончен + пропуск следующего |
| IDS-ловушка | — | — | — | сброс карты базового/среднего уровня |

### Ход

1. **2 действия** (3 с AI-Upgrade): шаг, взлом, атака, разовая способность, покупка
2. **Обязательное расширение сети** — положить тайл на открытую грань
3. Переход к следующему игроку

Купить карту — не действие, но купленная карта **включается только в начале вашего следующего хода**.

### Фазы (циклы по 5 кругов)

| Цикл | Название | Что меняется |
|---|---|---|
| 1 | Экспансия и изоляция | агрессия запрещена, чужие узлы неприкосновенны |
| 2 | Интеграция и конфликт | можно взламывать чужие узлы и атаковать |
| 3+ | Сингулярность и штурм | бомбы, Ransomware, штурм Маршрутизатора |

В конце каждого цикла — **выплата дохода** и перезагрузка разовых способностей.

### Финал

Как только кто-то набирает **15 очков**, в сеть выходит Центральный Маршрутизатор:
его ставит сам виновник торжества, куда захочет (к открытой грани).
Дальше **3 круга** — штурм. Кто возьмёт Маршрутизатор, тот резко прыгает в очках.

Предохранитель: если Маршрутизатор так и не открыли, партия закрывается на 30-м круге.

## Ransomware — как это работает

Способность сильного уровня. Сценарий: вы **вместе с соперником держите один узел**.

1. Вы активируете Ransomware → маркер соперника **шифруется**
2. С зашифрованного маркера **не идут очки и доход**
3. Соперник открывает панель «Узлы под Ransomware» справа и платит **3 Ко́ина**
4. Дань уходит вам полностью, блокировка снимается

Работает именно на **общем** узле — где стоят ваш маркер и чужой. На узле без своего
маркера способность не сработает.

---

## Что показано только вам

Приватность встроена в сервер, а не в интерфейс:

- **Закрытые тайлы** — браузер получает их как `unknown`. Через DevTools ловушки не подсмотреть
- **Состав Резерва Сети** — уходит только количество, не типы
- **Сниффер пакетов** — подсмотренные тайлы возвращаются **только тому, кто сканировал**
- **Карты соперников** — видны лишь те, что уже «включились»; скрытые не уходят вообще

## Настройка баланса

Почти всё живёт в **`server/game/config.js`**:

```js
POINT_VALUE        // очки за узел:  { basic:1, medium:2, hard:4, router:6 }
CAPTURE_BOUNTY     // разовый куш Ко́инов при захвате
INCOME_BY_TILE     // доход за цикл (по умолчанию = POINT_VALUE)
POINTS_TO_TRIGGER  // 15 очков → выходит Маршрутизатор
FINAL_ROUNDS       // 3 финальных круга
HARD_ROUND_CAP     // 30-й круг — принудительный финал
RANSOM_COST        // 3 C — дань за разблокировку
PHASE_LENGTH       // 5 кругов в цикле
SCORING_MODE       // 'cumulative' — сумма захватов | 'holdings' — только удержанное
```

Поменял число — перезапустил сервер, и баланс другой. Код движка трогать не нужно.

## Технологии и почему так

**React + Vite** — быстрый дев-цикл, поле рисуется SVG, зум и панорамирование без библиотек.

**Node + `ws`** — WebSocket вместо опроса: действие уходит и приходит мгновенно,
как за одним столом. Состояние комнаты живёт в памяти процесса.

**Сериализуемый ГПСЧ** — состояние партии это одно 32-битное число. Значит партию можно
целиком сохранить в БД и восстановить без потери детерминизма: броски кубиков, колода,
раздача рынка не «съедут». Задел на переезд в Redis/Postgres без правок движка.

**Все правила на сервере.** Клиент — тонкий: рисует то, что дали, и отправляет намерения.
Невалидное действие просто не проходит, подделать состояние или подглядеть скрытое нельзя.
